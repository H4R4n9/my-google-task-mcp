Google Tasks MCP 만들기

에이전트가 내 구글 할일을 직접 만들고 조회하게 한다. 코드는 에이전트가 쓰고, 제대로 됐는지는 내가 확인한다.

45분 · 5단계 준비물 계정 2개 제출 Fork + push
저장소 github.com/kakao-ai-tech/my-google-task-mcp

이 실습, 한 눈에

내가 말한다 에이전트가 판단 내 계정이 바뀐다 │ │ │ "이번 주 할일에 내가 만든 도구 중 구글 할일 앱에 병원 예약 넣어줘" → add_task 를 골라 호출 → 진짜로 생긴다 │ │ │ └───────── 이 사이를 잇는 것이 MCP ─────────┘

가짜 데이터를 다루는 실습이 아닙니다. 내 구글 계정의 실제 할일이 바뀝니다.

위 화면은 손으로 입력한 게 아닙니다. "내일 병원 예약, 모레 세탁물 맡기기, 금요일까지 생일 선물 사기" 라고 말한 결과입니다.

시작하기 전에

01구글 계정평소 쓰는 것. 새로 만들지 않습니다
02GitHub 계정결과물을 올릴 때 씁니다
03코딩 에이전트Claude Code · Codex · Gemini CLI 등 평소 쓰는 것
언어는 정해두지 않았습니다

내 컴퓨터에 이미 있는 런타임을 쓰면 됩니다. 뭐가 있는지 모르면 에이전트에게 물어보세요.

Step 1 3분

토큰 받기

목표 · 에이전트가 내 구글 할일에 접근할 수 있는 열쇠를 받는다.

내 할일은 나만 볼 수 있습니다. 그래서 "이 프로그램이 내 할일을 다뤄도 좋다" 는 허락을 구글에서 받아야 합니다. 그 허락증이 토큰입니다. Google Cloud 프로젝트를 만들 필요는 없습니다.

  1. developers.google.com/oauthplayground 접속
  2. 왼쪽 목록에서 Google Tasks API v1 펼치기
  3. https://www.googleapis.com/auth/tasks 체크
  4. Authorize APIs → 구글 로그인 → 허용
  5. Exchange authorization code for tokens 클릭
  6. Access token 복사
주의

1시간 지나면 만료됩니다. 만료되면 4~6번을 다시 하세요.
토큰을 소스코드에 직접 쓰지 마세요. 나중에 저장소에 올릴 때 같이 올라갑니다.

에이전트에게 맡기기

목표 · 도구 4개를 가진 MCP 서버를 만들고, 에이전트에 연결까지 해둔다. 코드는 에이전트가 쓴다.

무엇을 만드나

도구하는 일

list_tasklists내 할일 목록들을 조회한다

만들고 → 확인하는 짝이 두 번 반복되는 구성입니다.

그리고 README.md 를 함께 전달하세요. 도구 명세와 API 문서 링크가 다 거기 있습니다.

어느 폴더에서 열든 쓸 수 있게 전역 설정으로 등록해줘.
"전역으로" 를 꼭 붙이세요

Claude Code 는 기본이 "이 폴더에서만" 이라, 빼먹으면 다음 단계에서 도구가 하나도 안 보입니다. Codex 와 Gemini CLI 는 설정 파일이 원래 전역이라 신경 쓰지 않아도 됩니다.

④ 에이전트 재시작

등록만으로는 부족합니다. 도구 목록은 세션이 시작될 때 읽어들이므로, 에이전트를 한 번 껐다 켜야 반영됩니다.

여기서 "잘 되는지" 확인하려 하지 마세요

이 세션에서는 제대로 확인할 수 없습니다. 이유는 바로 다음에 있습니다.

여기서 세션을 바꿉니다

지금까지 쓰던 대화창을 닫고,
새 대화를 엽니다

같은 폴더든 다른 폴더든 상관없습니다. 전역으로 등록했으니 어디서 열어도 잡힙니다. 중요한 건 대화 기록이 비워진 상태입니다.

[방금까지 쓴 세션] 에이전트가 자기가 쓴 코드를 다 기억하고 있다 ↓ 도구 설명이 부실해도 "아까 내가 만든 그거" 라고 알아서 보완한다 ↓ 잘 되는 것처럼 보인다 ← 착각 [새 세션] 코드를 본 적이 없다. 도구 이름·설명·입력 스키마만 보인다 ↓ 실제 사용자가 쓰는 상황과 똑같다 ↓ 도구 설명이 충분한지가 진짜로 시험된다

MCP 도구의 이름·설명·입력 스키마는 에이전트가 읽는 사용설명서입니다. 만든 사람이 옆에서 거드는 상황에서는 그 설명서가 부실해도 굴러갑니다. 새 세션은 설명서만 남은 상태예요.

Step 4 14분

새 세션에서 확인하기

목표 · 새 세션에 내 MCP 가 잡히는지 확인하고, 자연어로 실제로 동작시킨다.

① MCP 가 잡혔는지 확인

새 세션에서 /mcp 를 입력합니다. 세 제품 모두 같은 명령입니다.

제품명령비고
Claude Code/mcp
Codex/mcp자세히 보려면 /mcp verbose
Gemini CLI/mcp/mcp list 도 됩니다

내가 만든 서버 이름과 도구 4개가 보이면 연결된 것입니다.

이렇게 나오면 성공 
> /mcp

  google-tasks                                    ✔ connected
    node /Users/me/my-google-task-mcp/src/index.js

    Tools (4)
      · create_tasklist
      · list_tasklists
      · add_task
      · list_tasks

안 보이면 순서대로 확인하세요.

1. 에이전트를 재시작했는가 ← 등록해도 재시작 전에는 안 보인다 2. 전역 설정으로 등록했는가 ← "이 폴더에서만" 으로 등록되면 안 보인다 3. 서버 실행 경로가 절대경로인가

② 자연어로 시켜보기

도구 이름을 말하지 말고, 그냥 하고 싶은 말을 합니다. 에이전트가 스스로 골라야 합니다.

에이전트에게 
"이번 주 할일" 목록 만들어줘
에이전트에게 
이번 주 할일에 세 개 넣어줘.
내일 병원 예약, 모레 세탁물 맡기기, 금요일까지 생일 선물 사기 (예산 5만원)
방금 무슨 일이 일어났나

tasklist_id 를 내가 입력한 적이 없습니다. 목록을 만들 때 받은 id 를 에이전트가 읽어서 다음 호출에 넣었습니다. 한 문장이 도구 호출 세 번으로 풀린 것도 에이전트의 판단입니다.

③ 구글 할일 앱에서 확인

브라우저나 스마트폰의 구글 할일을 열어봅니다. 방금 말한 것이 그대로 들어와 있어야 합니다.

④ 잘 안 되면 만든 세션으로 돌아가기

새 세션에서 도구가 안 불리거나 엉뚱하게 동작하면, 그건 도구 설명이 부족하다는 신호입니다.

만들던 세션으로 돌아가서 → 도구 설명을 고치고 → 다시 새 세션에서 확인

이 왕복이 이 실습에서 배우는 것입니다.

Step 5 필수

정리하기

목표 · 남겨두면 위험한 열쇠를 없애고, 전역에 등록한 MCP 를 걷는다.

① 토큰 폐기

받은 토큰과 함께 7일간 유효한 갱신 열쇠도 발급됩니다. 그냥 두면 7일간 내 계정을 조작할 수 있는 상태가 남습니다.

https://myaccount.google.com/permissions → Google OAuth2 Playground 찾기 → 액세스 권한 삭제

② MCP 등록 걷기

전역으로 등록했으므로 그냥 두면 앞으로 여는 모든 세션에 따라다닙니다.

터미널 
claude mcp remove google-tasks --scope user

Codex 나 Gemini CLI 를 썼다면 설정 파일에서 해당 항목을 지우면 됩니다. 계속 써보고 싶다면 남겨두어도 되는데, 토큰을 새로 발급받아야 다시 동작합니다.

제출물 정리

무엇을 올리나 — 세 가지
